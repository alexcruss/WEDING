# Aïcha & Malick — Site de mariage

Site de mariage réalisé pour **Aïcha & Malick**, avec génération d'un faire-part personnalisé en PDF.

**En ligne : [alexcruss.github.io/WEDING](https://alexcruss.github.io/WEDING/)**

## Ce que fait le site

- Présente le couple, le programme et les informations pratiques du mariage
- Génère un faire-part personnalisé au nom de chaque invité, téléchargeable en PDF
- Palette blanc, orange, café et rouge

## Technique

Site statique en HTML, CSS et JavaScript, avec génération de PDF côté navigateur, hébergé sur GitHub Pages.
